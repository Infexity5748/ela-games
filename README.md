# ELA Games

Separate static game hosting for The ELA Hub. Games must have a verified
redistribution licence or publisher permission before their files are included.

## Included Games

| Game | Author | Permission | Files |
| --- | --- | --- | --- |
| 2048 | Gabriele Cirulli | MIT | `games/2048/` |

Each game retains its licence and provenance. 2048 uses the author's complete
browser runtime with relative asset paths. No proprietary game packages have
been copied into this repository.

GitHub Pages serves this repository's main branch at `/`. The ELA Hub's Netlify
deployment is independent and is not triggered by updates to this repository.

This host does not promise that school networks will allow it.
